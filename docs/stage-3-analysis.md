# Аналитический этап

Задача: пополнение запасов магазина у дома.

1. Прогноз спроса: среднее за N дней без учёта дней, когда товара не было на полке.
2. Контроль сроков годности по правилу FEFO (минимальная куча heapq).
3. Расчёт заказа на поставку с округлением до кратности упаковки.

Запуск: `python -m src.retail.main`, тесты: `pytest -q`.
